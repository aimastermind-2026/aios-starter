# Source documents

Drop your original material here: business overview, strategy, brand voice, offer descriptions, best posts, talks, anything that explains your business.

- Any format works: Word, PDF, Google Doc downloads, pasted text.
- `/onboard` and `/grill-me` read these first, so they only ask you about what's missing.
- These are the originals. The current, cleaned-up version of each fact lives in `context/`. When something changes, update `context/`.
- Leave out client names and private client documents unless you've decided how to anonymise them.
