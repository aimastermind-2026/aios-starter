**How to read it**
- **How it connects:** API script, MCP connector, export file, or not yet connected.
- **Access:** read only, or read and write. Start read only.
- **Guide:** a short note in `references/` on how to use the connection (for example `references/apify-api.md`).
- **Last confirmed working:** the date a real read succeeded, not the date it was set up.

Keys go in `.env` only.
